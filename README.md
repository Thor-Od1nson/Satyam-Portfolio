# Satyam Singh Portfolio

Portfolio site built with Next.js, React, and Tailwind CSS.

## Scripts

```bash
npm run dev
npm run lint
npm run build
npm run start
```

## Environment

- `NEXT_PUBLIC_SITE_URL`: required for production metadata and canonical URLs.
- `VERCEL_PROJECT_PRODUCTION_URL`: fallback production host when deploying on Vercel.
